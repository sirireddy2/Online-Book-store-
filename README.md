# 📚 Online Book Store – Book Point

A responsive and user-friendly **Online Book Store Website** developed using HTML, CSS, and JavaScript. The website provides an attractive platform for users to explore featured books, discover new arrivals, view customer reviews, and read book-related blogs.

## ✨ Features

- **Home Section:** Attractive landing page with book highlights and promotional offers.
- **Featured Books:** Browse a collection of featured books with prices and ratings.
- **New Arrivals:** Explore newly added books through interactive sliders.
- **Search Interface:** Easy-to-access search bar for finding books.
- **Login Interface:** Sign-in form with username and password fields.
- **Customer Reviews:** Dedicated section to display customer feedback.
- **Book Blogs:** Read informative and engaging book-related articles.
- **Responsive Design:** Layout designed to adapt to different screen sizes.
- **Interactive Navigation:** Smooth navigation between different sections.
- **Book Sliders:** Dynamic book carousels for an engaging browsing experience.

## 🛠️ Technologies Used

- **HTML5** – Structures the website content and sections.
- **CSS3** – Styles the website with layouts, animations, and responsive design.
- **JavaScript** – Adds interactive features and dynamic behavior.
- **Swiper.js** – Creates interactive book sliders and carousels.
- **Font Awesome** – Provides icons for navigation and website elements.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A web browser such as Google Chrome.
- A code editor such as Visual Studio Code.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sirireddy2/Online-Book-store-.git
   ```

2. Open the project folder:

   ```bash
   cd Online-Book-store-
   ```

3. Open the `Book Store` folder.

4. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.
